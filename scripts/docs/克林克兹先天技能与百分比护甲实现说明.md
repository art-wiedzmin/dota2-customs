# 克林克兹先天技能（百分比护甲穿透）实现说明

## 一、Dota 2 原版克林克兹先天技能

### 1.1 KV 定义（npc_dota_hero_clinkz.txt）

```lua
"clinkz_infernal_shred"
{
    "AbilityBehavior"    "DOTA_ABILITY_BEHAVIOR_PASSIVE | DOTA_ABILITY_BEHAVIOR_SKIP_FOR_KEYBINDS | DOTA_ABILITY_BEHAVIOR_NOT_LEARNABLE"
    "SpellDispellableType"   "SPELL_DISPELLABLE_NO"
    "MaxLevel"           "1"
    "Innate"             "1"

    "AbilityValues"
    {
        "duration"               "5"
        "hero_stacks"            "3"
        "skeleton_stacks"        "1"
        "max_armor_piercing_pct" "20"
    }
}
```

### 1.2 机制说明

- **max_armor_piercing_pct = 20**：攻击时忽略目标 **20%** 的护甲（护甲穿透）
- **hero_stacks / skeleton_stacks**：英雄/骷髅攻击叠加层数
- **duration**：debuff 持续时间 5 秒

### 1.3 实现位置

该技能逻辑在 **Dota 2 引擎 C++** 中实现，不在 Lua。addon 中只有 KV 定义，没有对应 Lua 脚本。

## 二、护甲穿透 vs 护甲降低

| 类型 | 作用对象 | 效果 | 典型实现 |
|------|----------|------|----------|
| **护甲穿透** | 攻击者 | 攻击时忽略目标 X% 护甲 | 引擎内置 / MODIFIER_PROPERTY_IGNORE_PHYSICAL_ARMOR |
| **护甲降低** | 目标 | 给目标施加 -X 护甲 debuff | MODIFIER_PROPERTY_PHYSICAL_ARMOR_BONUS 返回负值 |

克林克兹先天是 **护甲穿透**（攻击者忽略目标部分护甲），不是给目标加护甲 debuff。

-- 攻击命中时给目标添加 modifier_ability_item_27_debuff
-- debuff 使用 MODIFIER_PROPERTY_PHYSICAL_ARMOR_BONUS 返回负值
function modifier_ability_item_27_debuff:GetModifierPhysicalArmorBonus()
    local stacks = self:GetStackCount()
    local extra_reduction = 1.5

end

## 四、在丛林肉搏中实现“百分比护甲”的几种方式

### 方案 A：百分比护甲降低（给目标加 debuff）

用 `MODIFIER_PROPERTY_PHYSICAL_ARMOR_BASE_PERCENTAGE` 或 `MODIFIER_PROPERTY_PHYSICAL_ARMOR_TOTAL_PERCENTAGE` 做百分比减甲。

```lua
-- 示例：攻击时给目标施加 20% 护甲降低 debuff
function modifier_xxx_debuff:DeclareFunctions()
    return {
        MODIFIER_PROPERTY_PHYSICAL_ARMOR_BASE_PERCENTAGE,  -- 对基础护甲乘算
        -- 或
        MODIFIER_PROPERTY_PHYSICAL_ARMOR_TOTAL_PERCENTAGE, -- 对总护甲乘算
    }
end

-- 返回 -20 表示护甲 × (1 - 0.2) = 80%，即降低 20%
function modifier_xxx_debuff:GetModifierPhysicalArmorBase_Percentage()
    return -20
end
```

### 方案 B：护甲穿透（攻击者忽略目标护甲）

用 `MODIFIER_PROPERTY_IGNORE_PHYSICAL_ARMOR`，使攻击者在计算物理伤害时忽略目标部分护甲。

```lua
-- 给攻击者加 modifier，使其忽略目标 20% 护甲
function modifier_xxx:DeclareFunctions()
    return {
        MODIFIER_PROPERTY_IGNORE_PHYSICAL_ARMOR,
    }
end

-- 返回值需查阅 Dota 2 API，可能是 0/1 或百分比
function modifier_xxx:GetModifierIgnorePhysicalArmor()
    return 1  -- 或具体百分比，视 API 而定
end
```

### 方案 C：在伤害过滤中手动处理（最可控）

在 `damage.lua` 的 `CustomSets:Damage_Filter` 中，对物理伤害做“等效护甲穿透”处理：

```lua
-- 当攻击者拥有百分比护甲穿透时，对物理伤害做补偿
if ca:HasAbility("ability_xxx") and dmtp == 1 then
    local ab = ca:FindAbilityByName("ability_xxx")
    local pierce_pct = ab:GetSpecialValueFor("armor_pierce_pct") or 20
    -- 伤害已按护甲计算，需用公式反推“忽略护甲”后的等效伤害
    -- 物理减伤公式: damage_reduction = armor * 0.06 / (1 + armor * 0.06)
    -- 忽略 20% 护甲 ≈ 目标护甲按 80% 计算，需按公式重新换算
    local ta_armor = ta:GetPhysicalArmorValue(false)
    local effective_armor = ta_armor * (100 - pierce_pct) / 100
    -- 根据 effective_armor 与 ta_armor 的差异，对 dm 做补偿计算
    -- （具体公式需按 Dota 物理伤害公式推导）
end
```

## 五、推荐实现：作为英雄先天词条

若希望做成类似克林克兹的 **先天被动**，可：

1. 在 `HeroData.hero_attr` 中增加 `wlsz`（物理护甲穿透百分比）
2. 在 `modifier_attr_buff` 中声明 `MODIFIER_PROPERTY_IGNORE_PHYSICAL_ARMOR`（若 API 支持百分比）
3. 或在 `damage.lua` 中根据 `wlsz` 对物理伤害做补偿计算

### 5.1 若使用 MODIFIER_PROPERTY_PHYSICAL_ARMOR_BASE_PERCENTAGE（目标 debuff）

攻击命中时给目标加 debuff，debuff 中：

```lua
function modifier_clinkz_armor_pierce_debuff:GetModifierPhysicalArmorBase_Percentage()
    return -20  -- 降低 20% 基础护甲
end
```

这样实现的是 **护甲降低**，效果类似“攻击该目标时目标护甲变少”，与克林克兹的“攻击者穿透护甲”在语义上略有不同，但数值上可达到相近效果。
