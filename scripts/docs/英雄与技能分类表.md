### 4.2 `SelectHero/Config.lua`（英雄池与 `HeroList` 不一致）

| 问题 | 说明 |
|------|------|
| **琼英碧灵 index=31** | `HeroList.muerta` 为 **`tp = 2`（敏捷）**，但 `SelectHero.HeroType.tp3` 含 **31**、`tp2` **不含 31**。随机/分路池与主属性展示可能不一致，建议统一。 |
| **陈 index=66** | `HeroList` 已配置 **chen**，但 **`HeroType.tp1/tp2/tp3` 均未包含 66**，该英雄可能不会进入按属性随机的池子。 |
| **暗影萨满 index=87** | `HeroList` 已配置 **shadow_shaman**，但 **`HeroType` 三组均未包含 87**，同上。 |
| **凯 index=12** | `HeroList` 已配置 **kez** 且 **`tp = 2`**，但 **`HeroType.tp2` 当前未包含 12**（池子从 11 跳到 13）。随机选敏捷英雄时可能抽不到凯，建议将 **12** 加入 `tp2`（及 `Rareness.rank_2.tp2` 如需）。 |
